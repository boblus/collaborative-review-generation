Peer review evaluation

1. Read the paper

Start by reading the full paper. Try to understand:
  • The research goals and key contributions.
  • The methods and experiments used.
  • The results, conclusions, and any major claims.

2. Evaluate a review

Your task is to assess whether the candidate review aligns in intent and quality with the reference review.

The candidate review was written based on a set of key points and judgments that were extracted from the reference review. Each key point represents an aspect (e.g., Novelty), and each judgment indicates the reference reviewer's stance (i.e., Strength or Weakness).

Note that neither the candidate review nor the reference review is a full review. They are excerpts from a complete review, which discuss the provided key points and judgments.

Please read the evaluation guidelines carefully before starting.
